# 🏠 น้องหอ: แชตบอต RAG ตอบคำถามหอพักนักศึกษา มจพ. ปราจีนบุรี

Web application แชตบอตที่ตอบคำถามเกี่ยวกับหอพักนักศึกษา เช่น ค่าเช่า ค่าน้ำไฟ เวลาปิดหอ กฎระเบียบ การแจ้งซ่อม Wi-Fi และที่จอดรถ ด้วยเทคนิค **RAG (Retrieval-Augmented Generation)** รองรับคำถามทั้งภาษาไทยและภาษาอังกฤษ

> ⚠️ ข้อมูลในโฟลเดอร์ `data/` เป็น **ข้อมูลจำลอง** ที่สร้างขึ้นเพื่องานเรียนวิชา NLP ไม่ใช่ข้อมูลหรือประกาศอย่างเป็นทางการของมหาวิทยาลัย

- **Streamlit App:** https://kmutnb-prachinburi-dorm-chatbot.streamlit.app
- **GitHub Repository:** https://github.com/ThanawinPTINE/NLP-SubTest2

## แนวคิดของ Domain

นักศึกษาที่พักในหอพักมักมีคำถามซ้ำ ๆ เช่น "ประตูปิดกี่โมง" "ค่าไฟหน่วยละเท่าไร" "แอร์เสียแจ้งซ่อมที่ไหน" ซึ่งคำตอบกระจายอยู่ในประกาศและคู่มือหลายฉบับ ทำให้ค้นหายาก และสำนักงานหอพักเปิดเฉพาะเวลาราชการ

"น้องหอ" ช่วยให้นักศึกษาถามคำถามเป็นภาษาธรรมชาติได้ตลอด 24 ชั่วโมง โดยตอบจากเอกสารของหอพักเท่านั้น พร้อมบอกแหล่งอ้างอิงทุกครั้ง และตอบว่า "ไม่พบข้อมูล" เมื่อเอกสารไม่มีคำตอบ แทนการเดาคำตอบเอง นอกจากนี้ยังมีคู่มือภาษาอังกฤษสำหรับนักศึกษาต่างชาติด้วย

## ฟีเจอร์

- คุยต่อเนื่องได้ ถามต่อแบบ "แล้วห้องแอร์ล่ะ" ระบบจะเขียนคำถามใหม่ให้สมบูรณ์ก่อนค้นหา
- แสดงเอกสารอ้างอิงใต้คำตอบทุกครั้ง พร้อมทำเครื่องหมาย ✅ ที่เอกสารที่ LLM อ้างอิงจริง และคะแนนความใกล้เคียง
- ปฏิเสธการตอบเมื่อไม่มีข้อมูลในเอกสาร ("ไม่พบข้อมูล")
- ตอบเป็นภาษาเดียวกับคำถาม (ไทยหรืออังกฤษ)
- ปุ่มตัวอย่างคำถาม เลือกโมเดล LLM และปรับจำนวนเอกสารที่ค้นหา (top-k) ได้จากแถบด้านซ้าย

## สถาปัตยกรรมระบบ

```
data/*.txt ──► 1. Loading & Cleaning ──► 2. Chunking ──► 3. Embedding ──► FAISS Index
                                                                              │
คำถามผู้ใช้ ──► เขียนคำถามใหม่ (ถ้าเป็นคำถามต่อเนื่อง) ──► Embedding ──► ค้นหา top-k ─┘
                                                                              │
              5. Groq LLM ◄── 4. Prompt (system prompt + บริบทพร้อมหมายเลข + คำถาม) ◄┘
                   │
                   ▼
        คำตอบพร้อมอ้างอิง [1][2] + แสดงเอกสารที่ใช้ในหน้าแชต
```

| ขั้นตอน | รายละเอียด | ไฟล์ |
|---|---|---|
| 1. Document Loading & Cleaning | อ่านไฟล์ `.txt`/`.md` ใน `data/` รวมรูปแบบ Unicode (NFC) ลบอักขระล่องหน (zero-width) แก้สระและวรรณยุกต์ไทยซ้ำหรือผิดลำดับด้วย `pythainlp.util.normalize` และลบช่องว่างซ้ำ | `rag.py` |
| 2. Chunking | แบ่งตามหัวข้อย่อย (`## `) ของเอกสาร เพื่อให้แต่ละ chunk เป็นเรื่องเดียวกัน ถ้าหัวข้อยาวเกิน 500 ตัวอักษรจะแบ่งต่อตามบรรทัดโดยซ้อนทับกัน 1 บรรทัด บรรทัดที่ยาวเกินจะตัดตามขอบเขตคำด้วย `pythainlp` (engine `newmm`) เพราะภาษาไทยไม่เว้นวรรคระหว่างคำ ได้ทั้งหมด 74 chunks | `rag.py` |
| 3. Embedding & Vector Search | ใช้ `intfloat/multilingual-e5-small` (รองรับภาษาไทย ขนาดเล็ก เหมาะกับ Streamlit Cloud) ใส่ชื่อเอกสารและหัวข้อไว้หน้า chunk เพื่อให้มีบริบทครบ normalize เวกเตอร์แล้วเก็บใน FAISS `IndexFlatIP` (เท่ากับ cosine similarity) โหลดโมเดลและสร้าง index ครั้งเดียวด้วย `@st.cache_resource` | `rag.py`, `app.py` |
| 4. Prompt Engineering | System prompt บังคับให้ตอบจากเอกสารอ้างอิงเท่านั้น อ้างอิงหมายเลข `[n]` ทุกข้อเท็จจริง ตอบ "ไม่พบข้อมูล" เมื่อไม่มีคำตอบ ตอบบางส่วนเมื่อมีข้อมูลบางส่วน และตอบภาษาเดียวกับคำถาม มี prompt แยกสำหรับเขียนคำถามต่อเนื่องให้สมบูรณ์ | `rag.py` |
| 5. LLM | Groq API (ค่าเริ่มต้น `openai/gpt-oss-120b`) แบบ streaming ใช้ temperature 0.1 เพื่อลดการแต่งคำตอบ แอปดึงรายชื่อโมเดลที่ใช้ได้จาก Groq อัตโนมัติ เผื่อโมเดลถูกถอดออก | `rag.py`, `app.py` |
| 6. Chatbot Interface | `st.chat_message` และ `st.chat_input` เก็บประวัติแชตใน `st.session_state` ส่งประวัติ 6 ข้อความล่าสุดให้ LLM และแสดงแหล่งอ้างอิงทุกคำตอบ | `app.py` |

## โครงสร้างไฟล์

```
├── app.py                  # หน้าเว็บ Streamlit (Chat UI)
├── rag.py                  # RAG pipeline: loading, chunking, embedding, FAISS, prompt, LLM
├── requirements.txt
├── test_questions.csv      # คำถามทดสอบ 15 ข้อ (มี 3 ข้อที่ไม่มีคำตอบในเอกสาร)
├── data/                   # เอกสารความรู้ 12 ไฟล์ รวม 24,371 ตัวอักษร
└── .streamlit/
    ├── config.toml
    └── secrets.toml.example
```

## แหล่งที่มาของเอกสาร

เอกสารทั้ง 12 ไฟล์ใน `data/` เป็นข้อมูลจำลองที่สร้างด้วย AI (Claude) โดยอ้างอิงรูปแบบทั่วไปของคู่มือหอพักนักศึกษาในมหาวิทยาลัยไทย ข้อเท็จจริงในทุกไฟล์ (ค่าเช่า เวลา ค่าปรับ เบอร์โทร) ถูกออกแบบให้สอดคล้องกัน เบอร์โทรศัพท์และอีเมลของหอพักเป็นข้อมูลสมมติ ยกเว้นเบอร์ฉุกเฉินระดับประเทศ (191, 199, 1669, 1323)

| ไฟล์ | เนื้อหา |
|---|---|
| `01_general_info.txt` | ภาพรวม อาคาร ประเภทห้อง สิทธิ์การเข้าพัก สำนักงานหอพัก |

| `04_dorm_rules_curfew.txt` | เวลาเปิด-ปิดหอ ผู้มาเยี่ยม เวลาเงียบ ข้อห้าม |
| `05_penalties_conduct_points.txt` | คะแนนความประพฤติ บทลงโทษ ค่าปรับ การอุทธรณ์ |
| `06_repair_requests.txt` | ช่องทางแจ้งซ่อม ระยะเวลาดำเนินการ ค่าใช้จ่าย |

| `12_international_student_guide_en.txt` | คู่มือภาษาอังกฤษสำหรับนักศึกษาต่างชาติ |

## วิธีใช้งาน

1. พิมพ์คำถามในช่องแชตด้านล่าง หรือกดปุ่มตัวอย่างคำถามที่แถบด้านซ้าย
2. ระบบจะค้นหาเอกสารที่เกี่ยวข้องแล้วให้ LLM ตอบ พร้อมหมายเลขอ้างอิง เช่น [1]
3. ใต้คำตอบจะแสดงชื่อไฟล์ที่ใช้อ้างอิง กด "📚 เอกสารที่ค้นพบ" เพื่อดูเนื้อหาของแต่ละ chunk และคะแนนความใกล้เคียง
4. ถามต่อเนื่องได้ เช่น ถาม "ค่าเช่าห้องพัดลมเท่าไร" แล้วถามต่อว่า "แล้วห้องแอร์ล่ะ"
5. กด "🗑️ ล้างประวัติแชต" เพื่อเริ่มบทสนทนาใหม่

## การรันในเครื่อง

```bash
pip install -r requirements.txt
```

สร้างไฟล์ `.streamlit/secrets.toml` (ดูตัวอย่างจาก `.streamlit/secrets.toml.example`) แล้วใส่ API Key จาก [console.groq.com](https://console.groq.com/keys)

```toml
GROQ_API_KEY = "..."
```

```bash
streamlit run app.py
```

ครั้งแรกจะดาวน์โหลดโมเดล embedding (~470 MB) และใช้เวลาสร้าง index ประมาณ 1 นาที

## การ Deploy บน Streamlit Community Cloud

1. Push โค้ดขึ้น GitHub (ไฟล์ `.streamlit/secrets.toml` ถูก `.gitignore` ไว้ จะไม่ถูกอัปโหลด)
2. ไปที่ [share.streamlit.io](https://share.streamlit.io) → **Create app** → เลือก repo, branch และไฟล์หลัก `app.py`
3. เปิด **Advanced settings** เลือก Python 3.11 และวาง `GROQ_API_KEY = "..."` ในช่อง **Secrets**
4. กด **Deploy** แล้วทดสอบเปิด URL จากโหมดไม่ระบุตัวตน (Incognito)

## การทดสอบ

`test_questions.csv` มีคำถามทดสอบ 15 ข้อ ทั้งภาษาไทยและอังกฤษ พร้อมคำตอบที่ถูกต้องและไฟล์ที่ควรค้นเจอ ในจำนวนนี้มี 3 ข้อที่ไม่มีคำตอบในเอกสาร (ข้อ 13-15) ซึ่งระบบต้องตอบว่า "ไม่พบข้อมูล"

ผลทดสอบการค้นหา (retrieval): คำถามที่มีคำตอบ 12 ข้อ ค้นเจอไฟล์ที่ถูกต้องใน top-4 ครบ 12/12 ข้อ

## ตัวอย่าง Prompt ที่ใช้สั่ง AI

โปรเจกต์นี้พัฒนาโดยใช้ Claude Code เป็นผู้ช่วยเขียนโปรแกรม ตัวอย่าง prompt ที่ใช้:

1. **เลือกหัวข้อ:** "ช่วยคิดหัวข้อ Web Application ระบบ RAG ข้อมูลตั้งต้นเป็นข้อมูลจำลองที่คุณสร้างให้ได้" แล้วเลือก "หอพักนักศึกษา มจพ. ปราจีนบุรี"
2. **สร้างข้อมูล:** "สร้างเอกสารความรู้ของหอพักนักศึกษา 12 ไฟล์ รวมไม่น้อยกว่า 15,000 ตัวอักษร ครอบคลุมค่าเช่า ค่าน้ำไฟ กฎระเบียบ การแจ้งซ่อม Wi-Fi ที่จอดรถ และมีคู่มือภาษาอังกฤษ ให้ข้อเท็จจริงทุกไฟล์สอดคล้องกัน"
3. **สร้างคำถามทดสอบ:** "สร้าง test_questions.csv อย่างน้อย 10 ข้อ พร้อมคำตอบที่ถูกต้องและไฟล์ที่มา มีคำถามที่ไม่มีคำตอบในเอกสารอย่างน้อย 2 ข้อ"
4. **สร้างระบบ:** "เขียน Streamlit app ระบบ RAG ที่ใช้ pythainlp ทำความสะอาดและแบ่ง chunk ภาษาไทย ใช้ sentence-transformers กับ FAISS ค้นหา เรียก Groq API ให้ตอบจากบริบทเท่านั้น อ้างอิงแหล่งที่มา และตอบว่า ไม่พบข้อมูล เมื่อไม่มีคำตอบ คุยต่อเนื่องได้และแสดงเอกสารอ้างอิงทุกครั้ง อ่าน API key จาก st.secrets"

### System Prompt ที่ใช้ในระบบ (ย่อ)

```
คุณคือ "น้องหอ" ผู้ช่วยตอบคำถามเกี่ยวกับหอพักนักศึกษา มจพ. ปราจีนบุรี
1. ตอบโดยใช้ข้อมูลจาก "เอกสารอ้างอิง" เท่านั้น ห้ามใช้ความรู้ภายนอก ห้ามเดา
2. ทุกข้อเท็จจริงต้องอ้างอิงหมายเลขเอกสาร เช่น [1] หรือ [2][3]
3. ถ้าเอกสารไม่มีคำตอบ ให้ตอบขึ้นต้นด้วย "ไม่พบข้อมูล" และแนะนำให้สอบถามสำนักงานหอพัก
4. ถ้าตอบได้บางส่วน ให้ตอบเฉพาะส่วนที่มีข้อมูล
5. ตอบเป็นภาษาเดียวกับคำถาม
6. ตอบกระชับ คงตัวเลขให้ตรงตามเอกสาร
```

ดู prompt ฉบับเต็มได้ที่ `SYSTEM_PROMPT` และ `CONDENSE_PROMPT` ใน `rag.py`
